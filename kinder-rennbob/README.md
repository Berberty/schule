# Kinder-Rennbob

Ein Rennbob für Kinder bis etwa 155 cm: 3D-gedruckte 4-mm-Schale (PETG), Kufen mit Edelstahlschiene, Bremsen, die bündig in der Seitenwand liegen. Ein Jugend-forscht-Projekt.

## Inhalt

| Pfad | Inhalt |
|---|---|
| `index.html` | Projektseite |
| `plan/` | Konstruktionsplan (3 Blätter, Stückliste) |
| `downloads/Kinder-Rennbob-Plan.pdf` | Konstruktionsplan als PDF |
| `downloads/Kinder-Rennbob-STL.zip` | Druckdateien Prototyp 1:10 (komplett mit Hebeln, Wanne und Hebel einzeln) |
| `img/` | Produktbilder |

## Veröffentlichen mit GitHub Pages

1. Ordnerinhalt in ein Repository hochladen (oder als Unterordner in ein bestehendes Pages-Repository).
2. *Settings → Pages → Deploy from a branch*, Branch `main`, Ordner `/ (root)`.
3. Die Seite ist dann unter `https://<konto>.github.io/<repository>/` erreichbar.

Alle Pfade sind relativ – die Seite funktioniert auch in einem Unterordner.
